#  Sentiment Analysis using NLP & Machine Learning

##  Overview
This project builds an end-to-end **Sentiment Analysis system** using NLP techniques and Machine Learning models.  
It classifies text into **positive** or **negative** sentiments by transforming raw text into meaningful numerical features.

---

##  Pipeline Workflow
Raw Text → Preprocessing → Feature Engineering → Model Training → Evaluation

---

##  NLP Preprocessing
- Lowercasing  
- Removing HTML tags & punctuation  
- Tokenization  
- Stopword removal  
- Stemming  

---

## Feature Engineering
- **Bag of Words (BoW):** Word frequency-based representation  
- **TF-IDF:** Importance-based representation (better performance)

---

##  Models Used
- Logistic Regression  
- Naive Bayes (MultinomialNB)  
- Decision Tree  

---

##  Evaluation Metrics
- Accuracy  
- Precision  
- Recall  
- F1 Score  

---

##  Key Insights
- TF-IDF performed better than BoW  
- Logistic Regression gave best results  
- Naive Bayes was fast and efficient  
- Decision Tree showed lower accuracy  

---
