#  AI Chatbot using Transformers

##  Overview
This project is a simple command-line AI chatbot built using Hugging Face Transformers and PyTorch.  
It uses the **Qwen 2.5 1.5B Instruct model** to generate human-like responses in real-time.

The chatbot maintains conversation history and provides helpful, concise answers to user queries.

---

##  Features
-  Interactive command-line chatbot
- Uses a powerful LLM (Qwen 2.5 1.5B Instruct)
-  Maintains chat history for context
-  Optimized response time (limited history)
-  Clean and polite responses using system prompt
-  Handles empty input gracefully
-  Exit anytime using `exit` or `quit`

---

##  Tech Stack
- Python 
- Hugging Face Transformers 
- PyTorch
